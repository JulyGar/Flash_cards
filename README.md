# Flashsci

## Resumen

Flashsci es una aplicación web para estudiar mediante **flashcards** o tarjetas de memoria. Su objetivo es ayudarte a repasar conceptos de forma rápida, sencilla y organizada.

El proyecto está desarrollado con **Angular CLI v22.2.6**. Este README explica lo básico para ejecutar la aplicación, compilarla y trabajar con ella durante el desarrollo.

## ¿Para qué sirve?

- Estudiar y repasar contenido con tarjetas de memoria.
- Ejecutar la aplicación en local para probarla o desarrollarla.
- Compilar el proyecto para producción.
- Ejecutar pruebas unitarias.
